# 👋 Caroline Maguire

Hi! I'm Caroline Maguire — a senior technical writer based in Cork, Ireland. 

I write and maintain the documentation for [CodeFusion Studio](https://developer.analog.com/docs/codefusion-studio/latest/user-guide), Analog Devices' open-source embedded development platform — authored in a docs-as-code workflow and merged upstream in [analogdevicesinc/codefusion-studio](https://github.com/analogdevicesinc/codefusion-studio).

I have over nine years experience documenting developer tools, APIs, and SaaS platforms, with a focus on clear, user-oriented content. I hold an MSc in Software Design with Artificial Intelligence, and I use AI tools like Claude Code daily in my documentation workflow. Always interested in how other technical writers are using AI to optimise their work — feel free to reach out!

---

## 🤖 What I've Been Building

- **Docs that keep up with the code**: a GitHub Agentic Workflow (gh-aw) that checks the codebase for changes and opens documentation PRs for me to review.
- **Docs pipelines**: GitHub Actions workflows that lint, build, test, and deploy the docs to GitHub Pages on every change.
- **Claude Code skills and plugins**: skills that check content against our style guide, and [CFS Skills](https://github.com/analogdevicesinc/codefusion-studio/tree/main/packages/cfs-skills), a public Claude Code plugin that lets users query the docs and run end-to-end command-line workflows.
- **Docs for AI assistants**: `llms.txt` and `llms-full.txt` so AI tools can find and cite the documentation accurately.
